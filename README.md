# 🚗 PW Motors - Calculadora de Veículos

Aplicativo Android desenvolvido em **Kotlin** como projeto acadêmico (Univesp), focado em realizar cálculos práticos relacionados a veículos (como consumo de combustível, custo por quilômetro rodado e comparação entre álcool e gasolina).

## 📱 Funcionalidades

- **Comparativo Álcool x Gasolina:** Calcula qual combustível é mais vantajoso financeiramente com base nos preços informados.
- **Cálculo de Consumo Médio:** Estima a média de km/l do veículo a partir da distância percorrida e litros abastecidos.
- **Estimativa de Custo de Viagem:** Calcula o gasto total previsto para um trajeto específico.
- **Interface Intuitiva:** Layout simples e direto para uso rápido no dia a dia.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Kotlin](https://kotlinlang.org)
- **IDE:** Android Studio
- **Build System:** Gradle (Kotlin DSL)
- **Plataforma:** Android SDK

## 🚀 Como executar o projeto

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Abra no Android Studio:**
   - Abra o Android Studio e selecione **File > Open**.
   - Navegue até a pasta onde você clonou o projeto e clique em **OK**.
3. **Sincronize e execute:**
   - Aguarde o Gradle baixar as dependências necessárias.
   - Conecte um dispositivo Android físico (com Depuração USB ativada) ou inicie um Emulador.
   - Clique no botão **Run** (ícone de *play* verde) na barra superior.
